# Benchmark — i sei riferimenti mantenuti

Controllo: 12 ottobre 2026. **T** = contenuto osservato nelle pagine ufficiali; **V** = verifica visiva nell'appendice `visual-observations.md`; **NV** = non verificato. Le metriche dei fornitori sono dichiarazioni commerciali, non risultati indipendentemente accertati. Per font/palette/mobile si rimanda ai campioni reali: non si deducono dal testo.

## Lettura comparativa

Il pattern comune è **bisogno riconoscibile → oggetto operativo → prova → invito concreto**. Il vantaggio di conversione è un'ipotesi progettuale, non un A/B test osservato. I dati testimonial restano del concorrente e non sono trasferibili a Melpis. La resa desktop/mobile e i limiti di acquisizione sono nell'appendice visiva, che integra tutte le schede.
